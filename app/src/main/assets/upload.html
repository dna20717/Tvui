Auf TV abspielen 📺

Mit diesem Kurzbefehl schickst du jede Seite aus Safari an den Fernseher. Findet er ein Video, spielt der TV es direkt ab. Sonst öffnet sich die Seite im TV-Browser.

  1. Unten auf Code kopieren tippen.
  2. App Kurzbefehle öffnen → + → Name: Auf TV abspielen
  3. Aktion „JavaScript auf Webseite ausführen“ hinzufügen, den vorhandenen Code löschen und deinen einfügen.
  4. Aktion „Inhalte von URL abrufen“ darunter hinzufügen. Sie nimmt automatisch das JavaScript-Ergebnis.
  5. Oben auf das ⓘ tippen → „Im Teilen-Menü anzeigen“ einschalten.
  6. In Safari: Teilen → Auf TV abspielen. Beim ersten Mal fragt das iPad nach Erlaubnis.
